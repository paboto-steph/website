# paboto.com

Website for PABOTO (Stephanie Pabotoy), creative consultant and photographer in Copenhagen. Built to win new clients: brands, venues, agencies and buyers in food and drink, hospitality, culture, music, fashion, film and corporate.

Styled after the Work Examples PDF: white pages, coral #F26363, Helvetica Neue Bold uppercase headings, Light body text, coral divider blocks.

Plain HTML, CSS and JS, no framework. Deploys as a static site (Vercel, Netlify, GitHub Pages).

## Editing
Pages are generated by `build.py`. Change the project list, copy or prices in `build.py`, then run:

```
python3 build.py
```

This writes `index.html`, `services.html` and one page per project in `work/`. Styles live in `styles.css`, interactions in `script.js`.

## Pages
- `index.html`: opens with one photo at a time (click to open the project), then intro, project index with sector filters, who I work with, price strip, how I work, info and contact.
- `work/*.html`: one page per project with challenge, idea, what I did, result and images.
- `services.html`: packages with prices and expandable deliverables, a small first step, and retainers.
